# Binary Tree DFS

C++ implementation of a binary expression tree using dynamic memory
and recursive depth-first traversals.

## Concepts

- Binary trees
- Dynamic memory
- Pointers
- Recursion
- Preorder traversal
- Inorder traversal
- Postorder traversal

## Features

- Count total nodes
- Count leaves
- Count internal nodes
- Calculate tree height
- Generate prefix notation
- Generate fully parenthesized infix notation
- Generate postfix notation
- Evaluate arithmetic expressions
- Free dynamically allocated memory
