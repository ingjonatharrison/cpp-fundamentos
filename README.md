# C++ Fundamentals

Repository containing my C++ exercises, university practices, programming challenges, and small projects developed throughout my studies.

The main purpose of this repository is to document my learning process and strengthen my understanding of programming fundamentals, data structures, memory management, file handling, object-oriented programming, and problem solving.

---

## 📚 Topics

The repository is organized progressively by topic:

| #  | Topic                       | Description                                                         |
| -- | --------------------------- | ------------------------------------------------------------------- |
| 01 | Variables                   | Variables, data types, constants, input and output                  |
| 02 | Conditions & Loops          | `if`, `else`, `switch`, `for`, `while`, `do-while`                  |
| 03 | Functions                   | Functions, parameters, return values and modular programming        |
| 04 | Arrays & Matrices           | Vectors, arrays, matrices and multidimensional arrays               |
| 05 | Pointers & Dynamic Memory   | Pointers, references and dynamic memory allocation                  |
| 06 | Strings                     | String manipulation and text processing                             |
| 07 | Structs                     | User-defined structures and structured data                         |
| 08 | Files                       | Text files and binary files                                         |
| 09 | Input Validation            | Data validation and error handling                                  |
| 10 | Data Structures             | Lists, queues, stacks and other data structures                     |
| 11 | Object-Oriented Programming | Classes, objects, encapsulation and other OOP concepts              |
| 12 | Binary Trees                | Binary trees and tree-based data structures                         |
| 13 | Discrete Mathematics        | Programming exercises related to discrete mathematics               |
| 14 | Small Projects              | Small applications and projects developed to apply learned concepts |
