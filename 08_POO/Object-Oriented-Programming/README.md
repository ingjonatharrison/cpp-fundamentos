# Object-Oriented Programming

Introductory C++ exercises focused on understanding the basic structure of objects and classes.

These exercises were developed as part of a university course and are intended to practice identifying:

- Classes
- Attributes
- Methods
- Objects
- Basic object structure

## Exercises

| # | Exercise | Main Concept |
|---|----------|--------------|
| 01 | Personal Library | Class and object modeling |
| 02 | Car | Attributes and methods |
| 03 | University Student | Object modeling |
| 04 | Bank Account | Class structure |
| 05 | Pet | Attributes and behaviors |
| 06 | Mobile Phone | Object modeling |
| 07 | Product | Class structure |
| 08 | Fan | Attributes and methods |
| 09 | Digital Clock | Object modeling |
| 10 | Coffee Maker | Classes and objects |
